- [ ] Selecionar 3 a 5 fontes.

- [ ] Testar variações de prompts.
- [ ] Registrar dificuldades e soluções.
- [ ] Criar resumo estruturado.
- [ ] Criar glossário.
- [ ] Criar prompts reutilizáveis.
- [ ] Revisar o README.
- [ ] Tornar o repositório público.
- [ ] Copiar a URL do GitHub.
- [ ] Colar a URL na entrega do desafio DIO.
